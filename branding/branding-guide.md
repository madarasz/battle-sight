## Logo Proportions and Sizing

| Element | Specification |
|---|---|
| Full logo | Icon height matches text height |
| Icon-only | 1:1 square aspect ratio |
| Minimum full logo width | 160 px |
| Minimum icon size | 32 × 32 px |
| Preferred app icon size | 512 × 512 px |
| Clear space | ¼ of the icon width |

### Usage guidelines

- Maintain consistent proportions when scaling.
- Preserve sufficient contrast against backgrounds.
- Use the icon-only version for small spaces.
- Prefer transparent backgrounds for flexible placement.
- Avoid stretching, rotating, or adding effects to the logo.
